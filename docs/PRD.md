# AI Career Copilot — Product Requirements Document

## Product Overview

AI Career Copilot is an AI-powered career assistant that helps
early-career candidates understand how their resume aligns with
a specific job description and identify actionable improvements.

## Core User Flow

Resume + Job Description
→ Analyze
→ Diagnose
→ Recommend
→ Prepare

## MVP

- Resume upload
- Job description input
- Resume parsing
- Job requirement extraction
- Candidate-job matching
- Match score
- Skill-gap analysis
- Prioritized recommendations
- Resume improvement suggestions
- Interview question generation
